## ▶️ How to Run

1. Install the Java Development Kit (JDK) on your system.

2. Clone this repository:

   ```bash
   git clone https://github.com/arunrajguru/AF-java.git
   ```

3. Open the project in your preferred Java IDE.

4. Navigate to the Java source file you want to execute.

5. Compile the program:

   ```bash
   javac FileName.java
   ```

6. Run the compiled program:

   ```bash
   java FileName
   ```

Replace `FileName` with the name of the Java class containing the `main()` method.
